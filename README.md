# EarnBook

A blockchain social platform where members publish posts, earn points, and climb a leaderboard. The product direction is a social layer for blockchain communities, with rewards for meaningful participation.

## Run
Open `index.html` in a modern browser. This repository contains a frontend prototype; integrations and payout flows must be configured and reviewed before production use.

## Versions
The latest continuation is the active `index.html`. The earlier `earnbook-full.html` source is retained as a comparison snapshot; previous commits remain in Git history.
